##  Projetos em Destaque no Portfólio

Dentro da minha página, apresento duas grandes experiências práticas:

1. **Sistema de Gerenciamento Escolar**
   * **Desafio:** Automatizar o controle de notas e faltas com foco em uma interface simples para os professores.
   * **Solução:** Desenvolvimento do Front-end utilizando componentes reutilizáveis para garantir uma navegação fluida, integrado com uma API para consumo de dados em tempo real.

2. **API de Catálogo de Filmes/Produtos**
   * **Desafio:** Desenvolver o back-end de um catálogo com funcionalidades completas de busca, paginação e cadastro (CRUD).
   * **Solução:** Construção de uma API RESTful estruturada em Java e Spring Boot, aplicando boas práticas de POO e validação de dados com banco de dados MySQL.
